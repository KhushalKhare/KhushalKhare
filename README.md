## Featured Projects

### Agentic LLM Router
A cost-aware routing system that decides whether a user query should go to a smaller or larger LLM based on complexity, ambiguity, and risk.

Built with:
FastAPI • Python • Groq API • Prometheus • Docker

Key parts:
- Small vs large LLM routing
- LLM-as-a-Judge fallback
- Structured JSON outputs
- Prompt protection checks
- Prometheus metrics for latency, routing decisions, and errors

### Invoice AI Agent
An agent-based invoice extraction system that reads invoice PDFs, validates extracted fields, and retries when the output is incomplete or malformed.

Built with:
LangGraph • FastAPI • Pydantic • Docker • Python

Key parts:
- PDF text extraction
- Structured invoice field extraction
- Pydantic validation
- Retry logic
- JSON-only output handling

---

### GPS to GTFS AI Matching System
A Graph Neural Network system for matching noisy bus GPS data with scheduled GTFS transit data.

Built with:
PyTorch • Airflow • PostgreSQL • Kubernetes • GCP

Key parts:
- Spatio-temporal graph modeling
- Trip, stop, and stop-sequence prediction
- Noisy GPS handling
- Real-world validation
- Around 85% matching accuracy and 0.78 precision
